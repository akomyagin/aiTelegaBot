## Решения пользователя (зафиксированы в плане §4.0 — не переоткрывать)

1. «Топик» = **источник/канал** в рамках темы (НЕ LLM-кластер); «тема» =
   существующие topics из /topics (Этап 8). Дубли-пересказы из разных
   источников схлопываются в один первоисточник.
2. Навигация в виде «тема»: inline-кнопки с ПОЛНЫМИ человекочитаемыми
   названиями топиков (одна на строку) + тот же список именами в тексте
   сообщения. Пользователь спросил «а можно их внутри сообщения сделать?» —
   ответ дан: inline-кнопки и есть часть сообщения (крепятся под текстом);
   текстовые ссылки в теле Telegram — только внешние URL.
3. LLM-бюджет: «все нравятся» (согласен на любой режим) — дефолт выбран
   планировщиком (§4.8: батчинг, ≈25–30 вызовов/день, прогон ≤5–6 мин,
   триггер пересмотра «прогон >10 мин»).
